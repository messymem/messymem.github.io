Abstract

Mobile manipulators deployed at home across many rooms and many visits should improve with experience: after failing to open a locked cabinet, or finding an object in a drawer, the robot should use that knowledge to avoid repeated mistakes and complete future tasks more efficiently. However, today's robots often treat each task as new. Currently, compact scene representations omit interaction-derived knowledge, raw video buffers quickly grow to become inefficient and difficult to query, and VLM planners reason at inference time without persistently updating what the robot knows.

Memory for mobile manipulation must be spatially grounded and queryable, updatable from interaction, and fine-grained enough to surface visual context that a text summary would lose. We present MessyMem, a memory system that enables mobile manipulators to learn from doing by building a compact 3D scene graph and associating it with learned interaction-derived properties and keyframes for visual detail. A task planner can use this memory to avoid repeated failures, reuse object locations, and recover visual context for long-horizon decisions. We evaluate MessyMem across multiple tasks in simulation and on a real mobile manipulator, showing that persistent interaction-grounded memory significantly improves long-horizon task success over representative baselines.

Three Properties of Robot Memory

1

Globally Queryable & Spatially Grounded

A compact 3D scene graph indexes observed objects with world-frame positions, so a query returns not only what the robot has seen but where to go to find it.

2

Updatable from Interactions

A VLM interaction analyzer reads a collage of each action window and writes back properties that passive observation cannot reveal — locked, empty, heavy, openable, contents.

3

Fine-Grained

A keyframe saver links selected images to scene-graph nodes, so the planner can recover visual detail a text summary would lose.
